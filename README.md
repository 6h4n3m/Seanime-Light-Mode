# Seanime Light Mode

A custom CSS override that brings a full light theme to [Seanime Denshi](https://github.com/5h4n3m/Seanime) (Web UI). It remaps all of Seanime's dark-mode-only color tokens, surfaces, and component styles to clean light equivalents without touching the underlying app code.

## Features

- Full light-mode color scheme with neutral grays and legible contrast
- Overrides for all major UI components: buttons, badges, alerts, inputs, modals, context menus, tabs, and more
- Media entry headers, episode cards, and torrent search rows all styled for light backgrounds
- Player, manga reader, and code blocks stay dark where appropriate
- Calendar, date picker, and popover surfaces fully themed
- Works with Seanime's built-in Custom CSS setting -- no extensions or forks required

## Installation

1. Open Seanime in your browser or Seanime Denshi.
2. Go to **Settings > User Interface > CSS > Custom CSS**.
3. Copy the entire contents of [`seanime-light-theme-override.css`](seanime-light-theme-override.css) and paste it into the Custom CSS text area.
4. Save settings -- the light theme applies instantly.
